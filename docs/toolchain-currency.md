# C# pack toolchain currency

The C# pack exposes two repeatable, machine-readable observations:

```text
python3 scripts/dev.py toolchain-report
python3 scripts/dev.py roslyn-report
```

`toolchain-report` covers the Roslyn frontend project, the host's installed
.NET SDK/runtimes, declared `PackageReference` and target framework values,
`global.json` SDK policy when present, restored `project.assets.json` package
versions, and the latest stable versions visible from NuGet.  `roslyn-report`
uses the same contract but limits package
observations to `Microsoft.CodeAnalysis*` and `Microsoft.Net.Compilers*`.

Both commands print JSON to stdout.  Use `--no-network` when an offline,
byte-stable observation is preferred; latest package entries then say
`not_queried` rather than pretending that the local installation is current.
Use `--output evidence/toolchain-report.json` to save the exact report for
`sourcebridge report-toolchains`.

## Evidence boundaries

The report keeps these facts separate:

- `observations.installed` comes from `dotnet --version`, `--list-sdks`, and
  `--list-runtimes`;
- `observations.declared` comes from the project XML and central package props;
- `observations.resolved` comes only from the restored assets file (missing
  assets are reported as unavailable); and
- `observations.latest` is a NuGet query, or an explicit unavailable/
  not-queried result.

None of these fields says that the compiler can convert C# or emit Rust.
`conversion_capability.status` is always `not_claimed`.  The report also never
creates an upgrade proposal merely because a newer package exists.

An upgrade proposal supplied with `--proposals` must include compatibility
evidence, a validation command/result, and an explicit `adopt` or `defer`
decision with an evidence reference.  A deferred proposal remains a recorded
decision; it is not silently adopted on the next report.

## Roslyn frontend

The current Roslyn frontend project is
`frontend/RenodeIngest/RenodeIngest.csproj`.  Its PackageReference declarations
are the source of truth for requested Roslyn versions.  The assets file is
generated by restore and is deliberately not committed; the report records its
path and unavailable state when restore has not happened.

This report is diagnostic evidence for toolchain maintenance.  It is not a
conversion certification and does not choose a .NET target framework, Roslyn
API policy, or NuGet upgrade on behalf of a maintainer.
